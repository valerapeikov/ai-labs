# Лабораторная работа

## Тема

**Мини-макс с альфа-бета отсечением**

## Цель работы

Изучить алгоритм Mini-Max и его оптимизацию с помощью альфа-бета отсечения, а также сравнить их эффективность по количеству проверяемых узлов и времени выполнения.

## Вариант

**Вариант 1**

* Глубина дерева: 5
* Ширина дерева: 2
* Листовые значения: фиксированные
* Игроки: MAX и MIN

## Теоретическая часть

Алгоритм **Mini-Max** используется для выбора оптимального решения в игровых деревьях. Игрок MAX старается получить максимальное значение, а игрок MIN — минимальное.

**Альфа-бета отсечение** является оптимизацией алгоритма Mini-Max. Оно позволяет не рассматривать некоторые ветви дерева, если заранее известно, что они не смогут повлиять на итоговое решение.

В результате альфа-бета отсечения результат остаётся таким же, как у обычного Mini-Max, но количество проверяемых узлов может уменьшиться.

## Ход работы

1. Было создано игровое дерево глубиной 5 и шириной 2.
2. Для листовых узлов были заданы фиксированные целые значения.
3. Реализован рекурсивный алгоритм Mini-Max.
4. Реализован рекурсивный алгоритм Mini-Max с альфа-бета отсечением.
5. Для обоих алгоритмов подсчитано количество проверенных узлов.
6. Измерено время выполнения каждого алгоритма.
7. Полученные результаты были сравнены.

## Результат

Оба алгоритма получили одинаковое итоговое значение.

При использовании альфа-бета отсечения часть ветвей дерева не проверяется, поэтому количество обработанных узлов уменьшается. Это позволяет повысить эффективность алгоритма, особенно при увеличении глубины игрового дерева.

## Вывод

В ходе лабораторной работы были изучены и реализованы алгоритмы Mini-Max и Mini-Max с альфа-бета отсечением. Было установлено, что альфа-бета отсечение позволяет сократить количество проверяемых узлов без изменения конечного результата. Таким образом, оптимизированный алгоритм является более эффективным при работе с большими игровыми деревьями.
