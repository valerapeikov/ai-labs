## 2. Теоретические сведения

Алгоритм Boids описывает коллективное движение с помощью трёх локальных правил. Каждый агент учитывает только соседей в пределах радиуса взаимодействия, глобального управления нет.

1. **Центрирование (Cohesion).** Агент стремится к центру масс соседей. Вектор правила: `C = (центр масс соседей) − (позиция агента)`.
2. **Выравнивание (Alignment).** Агент подстраивает скорость под среднюю скорость соседей. Вектор правила: `A = (средняя скорость соседей) − (скорость агента)`.
3. **Разделение (Separation).** Агент отталкивается от слишком близких соседей. Вектор правила: `S = −Σ (позиция соседа − позиция агента)` по соседям в радиусе разделения.

Итоговое ускорение агента равно взвешенной сумме:

```
a = w_c · C + w_a · A + w_s · S
```

Затем ускорение и скорость ограничиваются по модулю:

```
v = limit(v + a·dt, v_max),    p = p + v·dt
```

Из этих простых правил возникает сложное согласованное поведение стаи, хотя ни один агент не знает общей картины.

Все параметры вынесены в три словаря в начале файла и меняются без правки алгоритма. В анимации радиус и веса меняются слайдерами прямо во время работы.

### 4.2. Основные решения

- **Векторизация.** Состояния всех агентов хранятся в массивах NumPy формы `(N, 2)`. Попарные векторы между агентами считаются одной операцией, без вложенных циклов.
- **Поиск соседей.** Через матрицу расстояний и булеву маску `dist < radius`. Сам агент исключается. Если соседей нет, правила центрирования и выравнивания дают нулевой вектор, деления на ноль нет.
- **Синхронное обновление.** Ускорения всех агентов считаются по состоянию на начало шага и применяются после, поэтому порядок обхода агентов не влияет на результат.
- **Радиус разделения** (4 ед.) меньше радиуса взаимодействия (15 ед.). Иначе агенты отталкивались бы от всех соседей и стая не удерживалась бы.
- **Ограничения.** Ограничены и скорость (`v_max = 2`), и ускорение (`a_max = 0.3`). Без этого стая разгоняется неограниченно.
- **Границы.** Реализованы два способа.
  - *Циклические (тор)*: вылетевший за край агент появляется с противоположной стороны. Расстояния между агентами считаются по кратчайшему пути через границу, поэтому агенты у края видят соседей с другой стороны.
  - *Отражение*: координата зеркально возвращается в поле, соответствующая компонента скорости меняет знак.

### 4.3. Метрики

Для объективной оценки результатов добавлены три метрики:

- **order** = |средняя скорость стаи| / средний модуль скорости. Равна 1, если все летят в одну сторону, около 0 при хаотичном движении (мера скоординированности).
- **Среднее расстояние до ближайшего соседа** (мера плотности).
- **Число столкновений**: пар агентов ближе 0,5 ед.

## 6. Результаты

### 6.1. Влияние радиуса взаимодействия

Веса базовые (0.01 / 0.05 / 0.1).

| Радиус | order | Расстояние до ближайшего | Столкновения |
|---|---|---|---|
| 5 | 0.43 | 6.48 | 0 |
| 15 | 0.34 | 3.80 | 0 |
| 40 | 0.55 | 2.74 | 1 |

**Наблюдение.** При малом радиусе у большинства агентов мало соседей или нет совсем, стая распадается на мелкие группы, расстояние до ближайшего соседа наибольшее. С ростом радиуса группы объединяются, увеличиваются согласованность и плотность. При R = 40 агент видит почти всю стаю, и она ведёт себя как единое целое.

### 6.2. Вклад каждого правила

Радиус 15, остальные веса равны нулю.

| Активное правило | order | Расстояние до ближайшего | Столкновения |
|---|---|---|---|
| только центрирование (0.01) | 0.18 | 5.52 | 0.4 |
| только выравнивание (0.05) | 0.96 | 3.73 | 1.4 |
| только разделение (0.1) | 0.07 | 6.80 | 0 |

**Наблюдение.**
- Одно *выравнивание* даёт почти идеально согласованный полёт (order 0.96), но агенты не удерживаются вместе и ничто не защищает от сближений.
- Одно *центрирование* сближает агентов, но направления остаются разными, согласованного движения нет.
- Одно *разделение* только рассеивает агентов.

Устойчивая стая возникает лишь при сочетании всех трёх правил.

### 6.3. Влияние весов при полном наборе правил

Радиус 15.

| Конфигурация (w_c / w_a / w_s) | order | Расстояние до ближайшего | Столкновения |
|---|---|---|---|
| 0.01 / 0.05 / 0.1 (базовая) | 0.34 | 3.80 | 0 |
| 0.01 / 0.05 / **0** (без разделения) | 0.81 | 0.00 | ≈1019 |
| 0.01 / 0.05 / **0.5** (сильное разделение) | 0.53 | 4.18 | 0 |
| **0.1** / 0.05 / 0.1 (сильное центрирование) | 0.29 | 1.56 | 3.2 |

**Наблюдение.**
- *Без разделения* стая движется согласованно (order 0.81), но агенты сливаются в одну точку: около 1000 пар ближе 0,5 ед. Это наглядно показывает, что разделение необходимо для физически осмысленной модели.
- *Усиленное разделение* полностью устраняет столкновения и повышает order до 0.53, но стая становится рыхлее.
- *Усиленное центрирование* делает стаю самой плотной (расстояние 1.56) и приводит к первым столкновениям, при этом согласованность не растёт. Агенты «кипят» вокруг общего центра, а не летят единым потоком.

### 6.4. Обработка границ

Базовые параметры.

| Границы | order | Расстояние до ближайшего | Столкновения |
|---|---|---|---|
| Циклические | 0.34 | 3.80 | 0 |
| Отражение | 0.27 | 3.91 | 0 |

**Наблюдение.** Количественные метрики близки. Качественное различие заметно на анимации: на торе стая плавно «перетекает» через край, а при отражении агенты упираются в стены и разворачиваются, из-за чего реже сохраняют общий курс. Для данной задачи циклические границы удобнее, так как не искажают динамику у краёв.

## 7. Анализ

Влияние параметров на стаю можно свести к следующему.

| Параметр | Рост параметра приводит к | Слишком малое значение | Слишком большое значение |
|---|---|---|---|
| Радиус взаимодействия | больше связей между агентами, ростом согласованности | стая распадается на группы | вся стая реагирует как один агент, теряется локальность |
| `w_c` (центрирование) | росту плотности | стая рассеивается | сильное сжатие, столкновения |
| `w_a` (выравнивание) | росту согласованности направления | хаотичное движение | стая теряет манёвренность, плохо реагирует на границы |
| `w_s` (разделение) | росту дистанции между агентами | столкновения, слипание | рассеивание стаи |

Устойчивое скоординированное движение достигается при балансе: выравнивание обеспечивает общий курс, центрирование удерживает группу, разделение не допускает слипания. Базовые веса из задания (0.01 / 0.05 / 0.1) дают рабочую, но достаточно рыхлую стаю с умеренной согласованностью (order ≈ 0.34). Для более плотного и согласованного потока выравнивание стоит повышать относительно других правил (например, до 0.1–0.2) либо увеличивать радиус.

## 8. Выводы

1. Реализован алгоритм Boids в 2D-среде 100×100 с тремя правилами Рейнольдса, ограничением скорости и ускорения, двумя способами обработки границ и интерактивной анимацией со слайдерами параметров.
2. Радиус взаимодействия определяет масштаб коллективного поведения: малый радиус ведёт к распаду на мелкие группы, большой к единой стае.
3. Ни одно правило по отдельности не создаёт устойчивую стаю: выравнивание даёт согласованность без сплочённости, центрирование даёт сближение без общего курса, разделение только рассеивает.
4. Разделение критически важно: без него агенты сливаются в одну точку (≈1000 «столкновений»), а чрезмерное разделение рассеивает стаю.
5. Чрезмерное центрирование повышает плотность и число столкновений, но не повышает согласованность направления.
6. Циклические границы обеспечивают более естественную динамику, чем отражение.
