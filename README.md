# Лабораторная работа №1

## Тема

**Реализация конечного автомата для распознавания формальных языков**

## Цель работы

Целью лабораторной работы является изучение принципа работы детерминированного конечного автомата и реализация программы на языке Python для распознавания слов заданного формального языка.

## Постановка задачи

Необходимо реализовать конечный автомат, который распознаёт слова формального языка:

$$
L = \{a^n b^m \mid n \geq 0,\ m \geq 0,\ n+m \geq 1\}
$$

Это означает, что слово должно состоять из некоторого количества символов `a`, за которыми следует некоторое количество символов `b`.

При этом:

* количество `a` может быть равно `0`;
* количество `b` может быть равно `0`;
* одновременно `n = 0` и `m = 0` быть не может;
* после появления символа `b` символ `a` больше встречаться не должен.

### Примеры слов языка

| Слово    | Результат   |
| -------- | ----------- |
| `a`      | принимается |
| `b`      | принимается |
| `aaa`    | принимается |
| `bbb`    | принимается |
| `aaabbb` | принимается |
| `aab`    | принимается |
| `abbb`   | принимается |

### Примеры слов, не принадлежащих языку

| Слово  | Причина                      |
| ------ | ---------------------------- |
| `""`   | пустое слово                 |
| `ba`   | после `b` появился `a`       |
| `abab` | нарушен порядок символов     |
| `baba` | после `b` появился `a`       |
| `abc`  | содержит недопустимый символ |

## Алфавит

Алфавит автомата:

$$
\Sigma = \{a,b\}
$$

Автомат обрабатывает только символы `a` и `b`.

## Описание конечного автомата

Для распознавания языка используются три состояния:

* `q0` — начальное состояние;
* `q1` — состояние чтения символов `a`;
* `q2` — состояние чтения символов `b`.

Конечными состояниями являются `q1` и `q2`.

Начальное состояние:

```text
q0
```

Конечные состояния:

```text
q1, q2
```

## Таблица переходов

| Текущее состояние | Символ `a` | Символ `b` |
| ----------------- | ---------- | ---------- |
| `q0`              | `q1`       | `q2`       |
| `q1`              | `q1`       | `q2`       |
| `q2`              | ошибка     | `q2`       |

### Объяснение переходов

Из состояния `q0`:

* при чтении `a` переходим в `q1`;
* при чтении `b` переходим в `q2`.

В состоянии `q1`:

* символ `a` оставляет автомат в `q1`;
* символ `b` переводит автомат в `q2`.

В состоянии `q2`:

* символ `b` оставляет автомат в `q2`;
* символ `a` приводит к отклонению слова.

Таким образом, автомат разрешает структуру:

```text
aaa...bbb...
```

но не разрешает переход обратно от `b` к `a`.

## Схема автомата

```text
                  a
              ┌───────┐
              │       ↓
        ┌───────┐   ┌───────┐
        │  q0   │──>│  q1   │
        └───────┘ a └───────┘
           │           │
           │ b         │ b
           ↓           ↓
        ┌──────────────────┐
        │       q2         │
        └──────────────────┘
                  ↑
                  │ b
                  └────────
```

`q0` — начальное состояние, `q1` и `q2` — конечные состояния.

## Алгоритм работы

1. Устанавливаем начальное состояние `q0`.
2. Считываем символы входного слова по одному.
3. В зависимости от текущего состояния и символа выполняем переход.
4. Если встречается недопустимый символ, слово отклоняется.
5. Если после перехода в `q2` встречается `a`, слово отклоняется.
6. После обработки всего слова:

   * если автомат находится в `q1` или `q2`, слово принимается;
   * если автомат находится в `q0`, слово отклоняется.

## Реализация на Python

```python
def automaton(word):
    state = "q0"

    for symbol in word:

        if state == "q0":
            if symbol == "a":
                state = "q1"
            elif symbol == "b":
                state = "q2"
            else:
                return False

        elif state == "q1":
            if symbol == "a":
                state = "q1"
            elif symbol == "b":
                state = "q2"
            else:
                return False

        elif state == "q2":
            if symbol == "b":
                state = "q2"
            elif symbol == "a":
                return False
            else:
                return False

    return state == "q1" or state == "q2"


word = input("Введите слово: ")

if automaton(word):
    print("Слово принадлежит языку")
else:
    print("Слово не принадлежит языку")
```
